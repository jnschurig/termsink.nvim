================================================================================
                                                                 *termsink.nvim*

termsink.nvim is a colorscheme for NeoVim written in Lua that takes its colors
from the terminal it runs in, with built in support for native LSP, TreeSitter
and many more plugins.

Colors are read with the `termcolors` CLI, which must be on your PATH:

    brew install jnschurig/termcolors/termcolors

If the colors cannot be read, a built-in default palette is used. Run
`:checkhealth termsink` to see why.

Adapted from the material.nvim theme: https://github.com/marko-cerovac/material.nvim

Many Thanks to Marko Cerovac for providing such an excellent source theme.

2. Usage                                                   *termsink-usage*

    To use the default settings, just apply the theme

    If you are using Vim-Script:
        colorscheme termsink

    If you are using Lua:
        vim.cmd 'colorscheme termsink'

3. Configuration                                   *termsink-configuration*

What sets termsink.nvim apart from most Vim/NeoVim themes is the wide array
of options for customising the theme.

In order for these settings to take effect, they should be placed in your
init.vim/init.lua before applying the colorscheme

Options:

All other options are passed to a setup function

    + require('termsink').setup()

This is an example of the setup function with the default values:

    require('termsink').setup({
        contrast = {
        styles = {
            comments = {},
            strings = {},
            keywords = {},
            functions = {},
            variables = {},
            operators = {},
            types = {},
        },
        plugins = {},
        disable = {
            background = false,
            eob_lines = true,
        },
        lualine_style = "default",
        async_loading = true,
    })

    + styles  {table}
          Typographic attributes applied to syntax roles. Empty tables mean
          "default appearance". Any vim.api.nvim_set_hl attribute works:
          { italic = true }, { bold = true }, { underline = true }, etc.

    + source  {string}
          Which terminal `termcolors` reads, passed straight through as
          `termcolors --source <value>`: an emulator name ("rex",
          "ghostty") or an absolute path to an emulator binary.
          Default nil: detect from $TERM_PROGRAM, then the
          GHOSTTY_RESOURCES_DIR / REX_SESSION marker variables, then
          termcolors' own auto-detection.

    + disable  {table}
          - background: set true for a transparent terminal (NONE bg)
          - eob_lines:  hide end-of-buffer ~ tildes (default true)

    + lualine_style {string}
          Choose between two styles for lualine. can be "default" or "stealth"

    + async_loading  {bool}
          Load parts of the theme asyncronously for faster startup
          (turned on by default)

    + plugins  {table}
          To apply the theme to a plugin, set it in this table
          Available plugins:
            - blink
            - coc
            - colorful-winsep
            - dap
            - dashboard
            - eyeliner
            - fidget
            - flash
            - gitsigns
            - harpoon
            - hop
            - illuminate
            - indent-blankline
            - lspsaga
            - mini
            - neogit
            - neotest
            - neo-tree
            - neorg
            - noice
            - nvim-cmp
            - nvim-navic
            - nvim-tree
            - nvim-web-devicons
            - rainbow-delimiters
            - sneak
            - telescope
            - trouble
            - which-key
            - nvim-notify

4. Examples                                         *termsink-examples*

Example config in Lua:

    -- Theme style
    vim.g.termsink_style = 'deep ocean'

    -- Colorscheme settings
    require('termsink').setup({
        plugins = {
           "dap",
           "gitsigns",
           "indent-blankline",
           "neogit",
           "nvim-cmp",
           "nvim-tree",
           "nvim-web-devicons",
           "telescope",
           "which-key",
        },
        disable = {
            background = false,
            eob_lines = true,
        },
        lualine_style = 'stealth'
    })

    -- Apply the colorscheme
    vim.cmd 'colorscheme termsink'

5. Lualine setup                                   *termsink-lualine-setup*

    To enable the lualine themes, first set the theme
    in your lualine settings to `auto` or `termsink`

        require('lualine').setup {~
          options = {~
            -- ... your lualine config
            theme = 'auto'~
            or
            theme = 'termsink'~
            -- ... your lualine config
          }~
        }~

    Then, choose the style trough a variable called lualine_style
    in the theme setup function

    require('termsink').setup({~
        lualine_style = 'default' -- the default style
        or
        lualine_style = 'stealth' -- the stealth style
    })~

    If the theme, doesn't look right, it's probably because termsink.nvim
    is being loaded before lualine, causing the other termsink theme
    that comes built-in to lualine to be used.
    To fix this, either load termsink.nvim after lualine (preferred way)
    or set the lualine theme to one of these two values in your lualine settings

    require('lualine').setup {~
      options = {~
        -- ... your lualine config
        theme = 'termsink-nvim' -- the default style
        or
        theme = 'termsink-stealth' -- the stealth style
        -- ... your lualine config
      }~
    }~

6. Functions                                           *termsink-functions*

Material.nvim has built in functions that you can call or bind to a key

    + Use telescope.nvim to switch to a style
          :lua require("termsink.functions").find_style()~

    + Switch to a specific style
          Call the function for switching and pass in the name of the style
          that you want to switch to:
          :lua require('termsink.functions').change_style('palenight')~

    + Toggle the end of buffer lines
          Call this function if you want to toggle the visibility of the lines at the end of
          the buffer:
          :lua require('termsink.functions').toggle_eob()~

================================================================================
7. Mappings                                             *termsink-mappings*

You can map the built-in functions to keys
This will allow you to change the style and toggle the end-of-buffer lines
at keypress

Example:

nnoremap <leader>tf :lua require('termsink.functions').find_style()<CR>

nnoremap <leader>tm :lua require('termsink.functions').toggle_style()<CR>

nnoremap <leader>te :lua require('termsink.functions').toggle_eob()<CR>
